# Cucumber for Scala

[![Build](https://img.shields.io/github/actions/workflow/status/vbmacher/intellij-cucumber-scala/build.yml?style=flat-square)](https://github.com/vbmacher/intellij-cucumber-scala/actions?query=branch%3Amaster)
[![Version](https://img.shields.io/jetbrains/plugin/v/7460-cucumber-for-scala.svg?style=flat-square)](https://plugins.jetbrains.com/plugin/7460-cucumber-for-scala)
[![JetBrains Plugin Downloads](https://img.shields.io/jetbrains/plugin/d/7460-cucumber-for-scala?style=flat-square)](https://plugins.jetbrains.com/plugin/7460-cucumber-for-scala)

An [IntelliJ IDEA plugin](https://plugins.jetbrains.com/plugin/7460-cucumber-for-scala)
for navigating, writing, running and documenting Gherkin scenarios backed by the
[Cucumber Scala DSL](https://github.com/cucumber/cucumber-jvm-scala).

Start with the [feature guide](docs/getting_started.md) or explore the
[example project](example/README.md).

| Guide | Contents |
| --- | --- |
| [Installation](docs/installation.md) | IDE requirements, plugin installation, project prerequisites and development setup |
| [Getting started](docs/getting_started.md) | All features and links to their guides |
| [Navigation](docs/navigation.md) | Definitions, usages, hooks, table headers and requirements |
| [Editing](docs/editing.md) | Completion, documentation, generation, edge-case drafts, rename, numbering, tables, inspections, preview and export |
| [Workspace](docs/workspace.md) | Suite, Run History, Step Implementation and Scenario Search tabs |
| [Run and debug](docs/running.md) | Feature, scenario and Examples-row runs, breakpoints, results and failure explanations |
| [Configuration](docs/configuration.md) | Settings, project configuration file, mappings, inspections and run configurations |
| [Icons](docs/icons.md) | Gutter, result, breakpoint and tool-window icon rules |
